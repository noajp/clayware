# 紹介ページ（website/）

静的な HTML。トークンは `website/assets/tokens.css`、部品は `website/assets/site.css`。英語（`website/*.html`）と日本語（`website/ja/*.html`）を必ず両方直す。ビルド時に `web/public/homepage/` へ写される。

## 書き方

- 比喩を使わず、何ができるかをそのまま書く。「〜のように」「魔法」「相棒」などで飾らない
- 実装されている機能だけを書く。書く前に `.claude/PRODUCT.md` と `docs/about.md`、必要ならコードで確かめる
- 一文を短く。見出しは言い切りで、句点で終える
- 教育は「この製品に限らず、AI と業務の変革に向けた、個人の変化まで含めた包括的な支援」として書く

## 見た目

- 絵は製品そのもの：実際の画面のスクリーンショット（`assets/*-list.jpg` など、言語とライト / ダーク別）、実際の部品を HTML で組んだもの（ハブ、連携の一覧、実行の様子）。イラストや飾りの図形を作らない
- 外のサービスのロゴは `assets/logos/` に置く。新しいロゴは https://svgl.app/ から取り、ライトとダークで別の版があれば両方置く
- 文は写真や画面の上に重ねず、横に置く
- ヘッダの右端：言語とライト / ダークの切り替えを一つの錠剤形（`.prefs`）にまとめ、ログインは錠剤形のボタン（`.btn--pill`）
- 節の型は `site.css` にある（`.rows`・`.index`・`.steps`・`.conns` / `.conn`・`.run`・`.more` など）。新しいページも既存の型で組み、ページごとの CSS を作らない
- ヘッダとフッタのリンクは全ページで同じに保つ

## 確かめ方

- ブラウザペインで英語・日本語、ライト・ダーク、1440px と 390px を見る
- スマホ幅で並びが崩れていないか（並べ替えは CSS の `order` で）、横にはみ出していないか
- リンク切れがないか（新しいページは英語と日本語の両方から行けるか）
